## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us via email at:

**Lekedada@gmail.com**

We take all security reports seriously and will respond to your report as soon as possible. Please include as much detail as possible about the vulnerability, including steps to reproduce if applicable.
